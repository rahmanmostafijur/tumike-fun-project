# Money Heist: knowledge questions for review

Every knowledge question in the Money Heist pack, with its options and the correct answer, in English and Bangla. In the game the options are shuffled.

There are 28 questions over the five parts. Difficulty rises from Part 1 (easy) to Part 5 (for real fans). The full journey asks 14 of them and the quick game asks 6; the rest are spares for Plan B.

Every answer below has been fact-checked.

To fix a question, edit `src/packs/money-heist/knowledge.ts`. The correct option is always the first one written there.
