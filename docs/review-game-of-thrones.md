# Game of Thrones: content for review

Every knowledge question in the Game of Thrones pack, with its options and the correct answer, in English and Bangla, followed by every character and the result slot it fills. In the game the options are shuffled.

There are 32 questions, four per season, based on the TV series only. Difficulty rises from Season 1 (easy) to Season 8 (for real fans). The full journey asks 14 of them and the quick game asks 6; the rest are spares for the swap lifeline. No question or answer reveals a death or the ending.

To fix a question, edit `src/packs/game-of-thrones/knowledge.ts`; the correct option is always the first one written there. Characters live in `src/packs/game-of-thrones/characters.ts`. This file is generated from both, so regenerate it after any change.
